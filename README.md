TaskMate – ülesannete haldamise rakendus

Grupp: TAK26

1. Projekti nimi

Minu projekti nimi on TaskMate. Tegemist on veebipõhise ülesannete haldamise rakendusega, mis aitab kasutajal oma igapäevaseid tegevusi ja kohustusi organiseerida.

2. Eesmärk

Projekti eesmärk on luua lihtne ja mugav rakendus, mille abil saab kasutaja oma ülesandeid kirja panna, neid organiseerida ning jälgida nende täitmist.

Rakendus aitab paremini aega planeerida, vähendada unustamist ja hoida kõik olulised ülesanded ühes kohas.

3. Sihtgrupp

TaskMate on mõeldud:

Õpilastele ja tudengitele, kes soovivad hallata koolitöid ja koduseid ülesandeid.
Töötajatele, kes soovivad oma tööülesandeid organiseerida.
Kõigile inimestele, kes soovivad oma igapäevaseid tegemisi paremini planeerida.
4. Funktsionaalsus

Rakenduses saab kasutaja kasutada järgmisi funktsioone:

Ülesannete lisamine – kasutaja saab lisada uusi ülesandeid ja kirjutada nende kirjeldusi.
Tähtaegade määramine – igale ülesandele saab määrata tähtaja.
Ülesannete lõpetamine – kasutaja saab märkida ülesande tehtuks.
Ülesannete muutmine ja kustutamine – kasutaja saab olemasolevaid ülesandeid muuta või eemaldada.
Ülesannete filtreerimine – kasutaja saab vaadata kõiki, lõpetatud ja pooleliolevaid ülesandeid.
Ülesannete prioriteedid – kasutaja saab määrata ülesandele madala, keskmise või kõrge prioriteedi.
Ülevaade ülesannetest – rakendus näitab, kui palju ülesandeid on kokku, lõpetatud ja veel tegemata.
5. Tehnoloogiad

Projekti arendamiseks plaanin kasutada järgmisi tehnoloogiaid:

HTML – veebilehe struktuuri loomiseks.
CSS – veebilehe kujundamiseks ja kujunduse muutmiseks.
JavaScript – rakenduse funktsioonide ja kasutajaga suhtlemise programmeerimiseks.
Git ja GitHub – projekti versioonihalduseks ja koodi hoiustamiseks.
Visual Studio Code – programmeerimiseks kasutatav koodiredaktor.
6. Teostusplaan

Projekti loomine toimub järgmiste etappidena:

Projekti kavandamine ja funktsioonide planeerimine.
GitHubi repositooriumi loomine.
HTML-i abil veebilehe põhistruktuuri loomine.
CSS-i abil veebilehe kujundamine.
JavaScripti abil ülesannete lisamise, muutmise ja kustutamise funktsioonide loomine.
Ülesannete filtreerimise ja prioriteetide funktsioonide lisamine.
Rakenduse testimine ja vigade parandamine.
Projekti lõplik viimistlemine ja dokumenteerimine.
7. Valmisoleku kriteeriumid

Projekt loetakse valmis olevaks, kui:

Veebirakendus avaneb ja töötab korrektselt.
Kasutaja saab uusi ülesandeid lisada.
Kasutaja saab ülesandeid muuta ja kustutada.
Kasutaja saab määrata ülesannetele tähtaegu ja prioriteete.
Kasutaja saab märkida ülesandeid lõpetatuks.
Ülesandeid saab filtreerida nende staatuse järgi.
Rakendus on kujundatud arusaadavalt ja kasutajasõbralikult.
Kõik peamised funktsioonid on testitud ja töötavad vigadeta.
